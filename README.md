# One Word From Grandma

**Bottykins** sounds like Grandma has taken “bot” and turned it into an affectionate nickname, the sort of word she might text after meeting a new household gadget. The cuddly “-kins” ending supplies her warm, faintly bemused voice, while “Botty” keeps the AI connection clear and makes the joke land on its own. It feels more personal and surprising than simply calling the machine a robot or borrowing a familiar assistant’s name.

Run it with `python3 main.py`. The program writes the word to `/output/entry.txt`.

This entry is original work.
